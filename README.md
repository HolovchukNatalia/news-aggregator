# News Aggregator

A modern news aggregator application built with React, TypeScript, and TailwindCSS that fetches news from News API and manages configuration through Sanity CMS.

## Features

- News feed with filtering and sorting
- Search by keyword in article titles
- Topic classification based on CMS configuration
- Responsive design
- Modern UI with shadcn/ui components

## Tech Stack

- **React 18** - UI library
- **TypeScript** - Type safety
- **Vite** - Build tool
- **TailwindCSS** - Styling
- **shadcn/ui** - UI components
- **TanStack Query** - Data fetching and caching
- **React Router** - Routing
- **Sanity CMS** - Content management
- **News API** - News data source

## Prerequisites

- Node.js 18+ and npm
- News API key (get it from https://newsapi.org/)
- Sanity account (https://www.sanity.io/)
